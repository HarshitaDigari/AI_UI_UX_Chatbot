DesignBuddy: UI/UX Design Chatbot
DesignBuddy is a Streamlit-based chatbot that assists with UI/UX design by providing real-time advice, ideas, and feedback. It uses the Gemini API (gemini-1.5-flash) to generate concise responses for questions about design principles, tools, feedback, and ideas. This project is ideal for university students learning UI/UX design.
Features

AI-Powered Responses: Directly queries the Gemini API for all user inputs.
Streamlit UI: Simple, chat-style interface with message history.
Inbuilt API Key: No user input required for the Gemini API key.
Responsive: Works on desktop and mobile.
Error Handling: Displays API errors (e.g., invalid key, rate limits).

Prerequisites

Python 3.8+: Download and install from python.org. Ensure Python and pip are added to your PATH.
Verify installation:python --version
pip --version




Git: Optional, for cloning the project. Download from git-scm.com.
Gemini API Key: Obtain from Google AI Studio.

Setup Instructions
1. Clone or Download the Project (Optional)
If using Git, clone the repository:
git clone https://github.com/your-repo/designbuddy.git
cd designbuddy

Alternatively, download and extract the ZIP file from the repository.
2. Install Dependencies
Install the required Python libraries directly on your system using pip.
Install dependencies from requirements.txt:
pip install -r requirements.txt

The requirements.txt includes:

streamlit==1.31.1
google-generativeai==0.8.2
python-dotenv==1.0.1 (for secure API key management)

Verify installations:
pip list

Confirm streamlit, google-generativeai, and python-dotenv are listed.
3. Set Up the Gemini API Key
The chatbot uses an embedded Gemini API key for real-time responses.
Option 1: Hardcode the Key (Local Testing)

Open app.py in a text editor (e.g., Notepad++ or VS Code).
Find the line:GEMINI_API_KEY = 'AIzaSyDisMGPndMSZUab9sLmsjc7idryAQZ3xoM'


Replace 'AIzaSyDisMGPndMSZUab9sLmsjc7idryAQZ3xoM' with your full key (e.g., GEMINI_API_KEY = 'your-full-key').
Save the file.

Option 2: Use Environment Variable (Recommended for Deployment)

Create a .env file in the project folder:echo GEMINI_API_KEY=your-full-key > .env

Replace your-full-key with your actual key (e.g., AIzaSyDisMGPndMSZUab9sLmsjc7idryAQZ3xoM).
The app.py script automatically loads the key from .env using python-dotenv.
Add .env to .gitignore if using Git.

Get Your API Key

Visit Google AI Studio.
Sign in, create a project, and generate an API key.
Copy the key for use in app.py or .env.

4. Run the Chatbot
Run the Streamlit app:
streamlit run app.py

Open the provided URL (e.g., http://localhost:8501) in a browser (e.g., Chrome or Edge).
5. Use the Chatbot

Ask UI/UX questions (e.g., “What are UI/UX principles?” or “Give me a design idea”).
Responses are generated by the Gemini API, kept concise (<100 words).
Example Interaction:
User: “What are UI/UX principles?”
Bot: “UI/UX principles prioritize simplicity, consistency, and user focus. Use intuitive navigation, high-contrast colors, and accessibility.”
User: “Give me a UI design idea”
Bot: “Create a travel app with a coral and teal palette, swipeable destination cards, and a sticky search bar.”



Troubleshooting
Error: 'google-generativeai' package is not installed
Reinstall the package:
pip install google-generativeai==0.8.2

Verify:
pip show google-generativeai

Invalid API Key
Test your key using curl:
curl -H "Content-Type: application/json" -d "{\"contents\":[{\"parts\":[{\"text\":\"Hello\"}]}]}" -X POST "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=your-full-key"

If it fails, regenerate the key in Google AI Studio.
Rate Limits
The free tier allows 60 requests/minute. Check usage in Google Cloud Console.
Other Errors
Share terminal or UI error messages with your instructor or support for specific fixes.
Security Notes

Hardcoded Key: Hardcoding the API key in app.py is okay for local testing but risky for deployment (e.g., Streamlit Cloud). Use the .env file for security.
.env File: Ensure .env is not shared publicly or committed to Git.

Deployment (Optional)
To deploy to Streamlit Cloud:

Create a GitHub repository and push your project.git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/your-username/your-repo.git
git push -u origin main


Sign in to Streamlit Cloud with your GitHub account.
Create a new app, select your repository, and specify the branch (e.g., main).
In the app settings, add the Gemini API key as an environment variable:
Go to "Advanced Settings" > Add a secret: GEMINI_API_KEY=your-full-key.


Deploy the app. Once deployed, access it via the provided URL (e.g., https://your-app-name.streamlit.app).
